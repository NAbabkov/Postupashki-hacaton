## Проверенная исследовательская выгрузка

Проверенный путь: публичные страницы `https://t.me/s/<username>`, переход к предыдущим только по реально полученным ссылкам навигации `?before=…`, а не по выдуманным ID. Одна текущая страница не представляет весь период. Для пяти каналов сборщик сохранил исходный HTML и проверил достижение страницы старше 4 августа: основной 54 поста, алгоритмы 27, карьера 23, мемы 51, школьное направление 27. Полнота удалённой истории и всей рекламной сети неизвестна.

Для будущего загрузчика достаточно сохранить исходный URL, username / идентификатор канала при доступности, ID сообщения, время UTC, текст и исходные ссылки, источник пересылки, текущие просмотры, время получения и статус источника. Сохранять исходное значение отдельно от предполагаемой категории поста и продукта. При разрыве ID нельзя автоматически утверждать, что пропущенное сообщение было удалённой рекламой: причина неизвестна.

Если публичного HTML недостаточно, резерв — импорт экспорта, сделанного самим пользователем в [Telegram Desktop](https://telegram.org/blog/export-and-more), или разрешённый Telegram client API с собственной авторизацией и [собственным api_id](https://core.telegram.org/api/obtaining_api_id). Гарантии истории для конкретного канала из этой документации не следуют; конкретный экспорт нужно проверить. Авторизация и сбор через пользовательскую сессию в этой задаче не выполнялись.

Результат первого этапа — наблюдаемый календарь маркетинговых активностей и связи распространения между площадками. Чтобы назвать источник покупателя, дополнительно нужны индивидуальные контакты / промокоды / tracking-ID и способ связи с оплатой. Чтобы считать исторический ROMI, ещё нужны подтверждённые расходы. В учебном файле продажи частично изменены: совмещение с настоящими постами само по себе не доказывает настоящую эффективность бизнеса.
